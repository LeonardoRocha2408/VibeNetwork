# Vibe social network 
A social network project for learning that aims to demonstrate my knowledge in software development. 

## Technologies used
### Frontend
- JavaScript
    - React
    - Typescript
- CSS 
    - Tailwind CSS

### Backend
- C#
    - Entity Framework Core
    - ASP.NET Core
    - MediatR
- MySQL
- Docker

## Gets started
- Clone the repository
- Install all dependencies
- Configure your .env (frontend/backend)
- Run migrations
